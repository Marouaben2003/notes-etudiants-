# Exigences de sécurité

## 1. Authentification
- Chaque utilisateur doit s’authentifier.
- Les mots de passe ne doivent pas être stockés en clair.

## 2. Autorisation
- Chaque utilisateur accède uniquement à ses propres notes.
- Seuls les utilisateurs autorisés peuvent modifier les données.

## 3. Protection des données
- Valider les données saisies par les utilisateurs.
- Protéger les données contre les accès non autorisés.

## 4. Tests de sécurité
- Tester l’authentification.
- Tester les accès non autorisés.
